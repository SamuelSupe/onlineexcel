# OnlineExcel v0.1.1

npm 首发版本。电子表格功能与 v0.1.0 相同，本版更新 npm 发布配置、版本握手信息和安装文档，保留原有 v0.1.0 GitHub 归档。

```sh
npm install onlineexcel
npx onlineexcel-copy-assets public/onlineexcel
```

```js
import { createWorkbook, mountEditor } from "onlineexcel";

const workbook = await createWorkbook({ workerUrl: "/onlineexcel/worker.js" });
const editor = mountEditor(document.querySelector("#sheet"), {
  workbook,
  locale: "zh-CN",
});
await editor.ready;
```

为 `#sheet` 设置明确高度，例如 600px；部署时复制完整 Worker 与依赖 chunk。ESM、浏览器脚本、类型声明和 React/Vue 可选入口均包含在包内。

- [npm 包](https://www.npmjs.com/package/onlineexcel)
- [SDK 接入指南](https://github.com/SamuelSupe/onlineexcel/blob/main/docs/sdk.md)
- [兼容矩阵](https://github.com/SamuelSupe/onlineexcel/blob/main/docs/compatibility.md)
- [完整验证记录](https://github.com/SamuelSupe/onlineexcel/blob/main/docs/validation.md)

本版通过 212 项行为测试、类型检查和构建，安装包通过 ESM/IIFE 导出一致性、独立安装、XLSX 往返及 TypeScript 消费者检查。浏览器交互、独立 Excel 文件及容量测试沿用上一功能版本的已记录结果，本版不作新的性能或桌面 Excel 兼容性承诺。
