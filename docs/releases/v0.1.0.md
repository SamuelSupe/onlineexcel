# OnlineExcel v0.1.0

首个 GitHub 发布版本：可嵌入浏览器应用的电子表格库，使用 TypeScript、自主数据模型、Worker 计算、Canvas 网格及 XLSX 映射。使用 MIT 许可证。

## 主要能力

- 多工作表、区域编辑、格式、合并、冻结、排序筛选、查找替换、剪贴板、拖拽填充和事务撤销。
- 187 个公式函数、跨表与命名区域引用、增量重算及动态数组；未知公式保留原文并报告。
- XLSX、CSV 和 JSON 导入导出，结构化兼容诊断和有损导出确认。
- 可选自动保存、IndexedDB 草稿恢复、保存状态和失败重试；存储位置由宿主决定。
- 可筛选并定位单元格的诊断面板、50%～200% 真实网格缩放、数据边界跳转、格式刷和快捷键帮助。
- 简体中文、繁体中文、英文、日语和韩语；ESM、浏览器脚本、Worker、类型声明与 React/Vue 可选入口。

## 安装

下载本 Release 的 `onlineexcel-0.1.0.tgz`，在应用目录运行：

```sh
npm install ./onlineexcel-0.1.0.tgz
npx onlineexcel-copy-assets public/onlineexcel
```

```js
import { createWorkbook, mountEditor } from "onlineexcel";

const workbook = await createWorkbook({ workerUrl: "/onlineexcel/worker.js" });
const editor = mountEditor(document.querySelector("#sheet"), {
  workbook,
  locale: "zh-CN",
});
await editor.ready;
```

`#sheet` 需有明确高度，例如 600px。请一起部署 Worker 与依赖 chunk；`onlineexcel-copy-assets` 会复制完整资产。浏览器无需构建工具时使用包内 `dist/onlineexcel.js`。

当前没有发布到 npm registry。Release 附带 `SHA256SUMS`，可用 `shasum -a 256 -c SHA256SUMS` 校验下载的安装包。

## 验证与边界

发布代码已通过 OrbStack / Node 24 的 212 项行为测试、TypeScript 检查、构建，以及本机 Chrome 的完整集成检查。安装包通过 ESM/IIFE 导出一致性、独立安装、XLSX 往返和 TypeScript 消费者检查。详细环境与验证范围见 [验证记录](https://github.com/SamuelSupe/onlineexcel/blob/main/docs/validation.md)。

本库不是桌面 Excel 的完整兼容替代品。多人协作、VBA、旧 `.xls`、加密文件、完整图表/透视表编辑、手机完整编辑和打印排版不在本版范围内。桌面 Excel 的实机打开、重算和保存仍待验证；性能数据保留原测量时间，不作为本次重新验收的承诺。

自动保存采用完整快照，单个存储键应只有一个写入控制器；不提供跨标签页或跨设备冲突合并。其他边界见 [兼容矩阵](https://github.com/SamuelSupe/onlineexcel/blob/main/docs/compatibility.md)，接入方法见 [SDK 指南](https://github.com/SamuelSupe/onlineexcel/blob/main/docs/sdk.md)。
