# 0.1 兼容矩阵

本文对应 0.1.1。**已实现**表示有可运行的代码和列出的行为验证，不表示覆盖桌面 Excel 的所有边界。库只在浏览器中处理数据，不上传文件。

## 编辑与模型

| 能力       | 状态与边界                                                                                                                                                                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 稀疏工作簿 | 多表、稳定表 ID、共享样式、版本化 JSON；默认每表 100,000 × 100，可配置至 Excel 的行列地址上限                                                                                                                                                                  |
| 编辑       | 单格/区域、公式栏、删除内容、行列增删、宽高和隐藏、工作表增删/重命名/排序/复制/隐藏与恢复、各表视图恢复；行高列宽批量设置及自动适应（跳过合并行列）                                                                                                            |
| 格式       | 字体、字号、粗体/斜体/下划线、RGB 字色/底色、四边细实线、外边框/清除边框、水平/垂直对齐、换行、自定义数字格式输入                                                                                                                                              |
| 数字格式   | 保存格式原文；显示支持常用小数、分组、百分比、货币、科学计数、日期时间。新增正/负/零/文本节、数字条件节、常用颜色节、分数、累计时长及基本会计留白；区域代码仅提取货币符号，仍不保证地区化月份和所有会计填充效果                                                |
| 合并       | 合并/拆分；合并非空区域时拒绝静默丢弃其他单元格，拒绝向合并区域非左上角写入隐藏内容；编辑器复制/粘贴完整合并区域；部分合并粘贴拒绝，copyRange API/排序/填充仍需先拆分                                                                                                                              |
| 冻结       | 左上角行列冻结、横纵滚动；不提供独立 split 窗格                                                                                                                                                                                                                |
| 排序       | API/UI 多关键字稳定排序；UI 默认保护标题、提示扩展相邻数据，可明确取消标题选项；区域内公式相对引用随行平移                                                                                                                                                     |
| 筛选       | 标题行 + 跨列 AND；每列最多两个比较条件，或一个 OR 值列表（含空白），UI/JSON/XLSX 支持；颜色、图标、Top10、日期分组及任意 OR 条件树未实现                                                                                                                      |
| 剪贴板     | 同工作簿复制保存当时的值、公式和格式，可重复粘贴并调整引用；剪切更新引用。外部 TSV 和基本 HTML 表格输入，支持 rowspan/colspan 与 br 换行；外部公式形文本默认保留为文本；同页面跨实例保留内部快照的公式和基础样式；支持仅值/公式与值/仅格式/转置，源和目标跳过隐藏行列；外部剪贴板不保证完整样式 |
| 填充       | 重复区域、相对引用平移、一维等差数字源向前/向后扩展，非等差模式重复且不改写源值；不推断日期/月名等高级序列                                                                                                                                                                                      |
| 查找替换   | 文本值/计算值及溢出结果连续查找、F3 回绕、大小写/整格匹配；文本常量替换；不重写公式文本，不提供正则搜索                                                                                                                                                        |
| 撤销       | 差异历史，每批事务一个历史项，默认 100 项，可配置为 0；导入成功清空历史；JSON 不保存历史                                                                                                                                                                       |
| 键盘与输入 | 方向键、Shift 扩展选区、Tab/Enter、Home、PageUp/Down、F2、F3 查找、F4 引用切换、删除、复制粘贴、撤销重做；Ctrl/Meta+方向键跳至数据边界，配合 Shift 扩展；F1 快捷键帮助；中文使用真实 DOM 输入框及 composition 事件                                                                               |
| 宿主       | 无 React/Vue 运行时依赖、Shadow DOM、CSS 变量、独立 Worker、可配置资产路径、只读 UI、工具栏显隐；简体中文/繁体中文/英文/日语/韩语界面，按实例配置 locale                                                                                                       |

默认面向桌面键鼠。手机完整编辑、打印分页、完全等同 Excel 的快捷键和屏幕阅读器体验均未验收。

## 公式

共 **187 个独立函数**，按英文规范名称计数，前缀兼容和别名不重复计数。每个函数的参数及特殊限制见 [版本化清单](functions.md) 与 [机器可读清单](functions.json)。

| 能力      | 状态与边界                                                                                                                                             |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 表达式    | AST 解释执行，不使用 eval；算术、比较、连接、百分比、数组常量                                                                                          |
| 引用      | A1 相对/绝对、跨表、整行/整列、工作簿级命名区域；公式编辑支持鼠标选取/拖选引用和本次引用高亮；不支持外部工作簿、3D、结构化表引用、命名公式、LET/LAMBDA |
| 依赖      | 直接与区域依赖索引、增量重算、跨表传播、循环诊断 #CYCLE!；TODAY/NOW/RAND 在编辑触发重算时更新                                                          |
| 引用调整  | 复制、填充、剪切、增删行列、重命名/删除表。无法解析的公式保留原文并诊断，不能调整其内部引用                                                            |
| 条件/查找 | SUMIFS、COUNTIFS、AVERAGEIFS、INDEX/MATCH、XLOOKUP/XMATCH 等，具体参数范围见函数清单                                                                   |
| 动态数组  | FILTER、SORT、SORTBY、UNIQUE、SEQUENCE、TRANSPOSE、TAKE/DROP、堆叠等；A1#、结果保护、遮挡/合并冲突 #SPILL!、清除旧结果与依赖重算                       |
| 动态边界  | 单个数组最多 1,000,000 个结果；迭代传播有界；不支持旧式 CSE 固定区域计算、表内数组及跨工作簿数组                                                       |
| 日期      | 1900/1904 序列系统、1900 虚构闰日、UTC 日期运算；DATEVALUE 接受确定性的 ISO 年月日；不推测宿主地区日期文本                                             |
| 财务      | PMT/FV/PV/NPER/NPV/IRR/XNPV/XIRR/RATE 等；数值迭代在不收敛时返回错误；不是完整 Excel 财务函数库                                                        |
| 未知公式  | 原文保留，当前结果为错误并给出诊断；丢弃旧文件缓存，绝不把旧缓存当作重新计算结果                                                                       |

浮点计算使用 JavaScript Number；没有逐函数覆盖所有 Excel 精度、转换、排序规则和历史兼容行为。别名 STDEV/VAR 等旧拼写不属于能力保证，使用清单中的规范名称。

动态数组行为参考 [Microsoft 溢出说明](https://support.microsoft.com/en-us/excel/dynamic-array-formulas-and-spilled-array-behavior)，这里只实现矩阵中列明的子集。

## 文件

| 项目            | 读写行为                                                                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| XLSX 数据       | 数值、布尔、文本、错误值、共享字符串/内联字符串；输出使用内联字符串                                                                                       |
| XLSX 公式       | 普通/共享公式导入；输出公式与本引擎计算缓存，并要求 Excel 打开时重算；支持动态数组元数据与未来函数前缀                                                    |
| XLSX 样式       | 基本字体、RGB/主题色、纯色填充、四边框、基础对齐、数字格式；非细线归一化，扩展索引调色板近似，均报告损失                                                  |
| XLSX 表属性     | 合并、冻结、显式行高/列宽、隐藏行列、比较/值列表筛选、全局矩形命名区域、日期系统、隐藏工作表、基础验证/条件格式及无密码保护                               |
| XLSX 筛选隐藏行 | 文件未区分手动隐藏和筛选隐藏；有可恢复筛选时重新计算该范围内隐藏行，并报告手动隐藏可能需要重设                                                            |
| XLSX 默认尺寸   | 未逐格指定的默认行列尺寸归一化为库默认值并报告；导入的可编辑范围至少为默认 100,000 × 100，而非原工作簿的空白容量设置                                      |
| 特殊日期/数组   | ISO 日期类型单元格按文本导入并报告；旧固定数组转为动态数组并报告，不承诺同等结果                                                                          |
| CSV             | UTF-8、BOM、逗号或单字符分隔、引号、多行字段；API 默认文本，可按列指定类型；UI 提供编码/分隔符/类型预览；导出单表计算值（包括溢出结果），不保留样式和公式 |
| JSON            | schema version 1，无损保存本库模型内的数据、原公式、样式、元数据和诊断；重新加载时重算                                                                    |
| 不支持对象      | 透视表、打印设置、富文本细节、外部链接、附加文档属性，以及未支持的验证/条件格式变体进入兼容报告                                                           |
| 不支持格式      | 旧 .xls、加密/密码文件、VBA/宏工作簿不支持；不运行宏或外部链接                                                                                            |

本实现依据 [ECMA-376 的包和 SpreadsheetML 结构](https://ecma-international.org/publications-and-standards/standards/ecma-376/)，不宣称完整 OOXML 规范认证。未建模的内容不会原样转存；兼容报告按已识别的部件、关系和功能产生，不能保证识别未来扩展中的所有信息损失。

有损 XLSX 导出默认抛出 CompatibilityError，包含 diagnostics；宿主或 UI 明确确认后通过 allowLossy=true 导出。未知公式自身保持原文，diagnostics 会提示当前计算结果的限制。桌面 Excel 的实机打开、重新计算和保存尚待验证；openpyxl 的独立读写证据不能替代该项。

## 资源边界

- 单次 getRegion/getValues 最多 200,000 格；大范围读取请分块。
- 编辑器选区统计与复制最多 100,000 格；格式操作一次最多 1,000,000 格。
- XLSX 压缩输入最大 128 MiB，展开合计 512 MiB，单部件 256 MiB，最多 10,000 个部件。拒绝 DTD/外部实体。
- 大量填充/排序仍需要保存实际变更的差异，历史项不是零成本；百万单元格的文件往返可能占用数 GiB 内存，实测见 [验证记录](validation.md)。
- 取消在协作检查点完成；当前同步阶段不能抢占，导入在解析和重算成功且检查取消后才替换工作簿。

值列表筛选按计算值的文本比较，不完整模拟 Excel 按地区与数字格式生成的筛选候选项。自动适应尺寸只针对当前浏览器可用字体；不提供打印尺寸一致性保证。宿主可用 commitEdit/getEditState/cancelEdit 与 destroy({commit:true}) 管理草稿，详见 API 文档。

## 本轮新增的办公边界

- 基础验证支持下拉列表、数值/整数/日期上下限和文本长度；条件格式支持值比较与文本包含。UI 提供底色规则，API 支持基础字体、数字格式、对齐、换行和边框样式；对应 DXF 样式可进行 XLSX 往返。未支持的条件样式变体进入有损报告。保护用于防止误编辑，没有密码认证功能。带密码的外部保护会归一化并明确报告。
- 名称管理器支持列出、定位、修改名称和范围、删除及撤销，仍只支持工作簿级矩形名称。
- 公式草稿可在滚动后继续选取引用；工具栏反映选区格式和混合状态；筛选统计及复制基于可见数据。
- 图片、传统注释、结构化表和绘图关联文件通过 OOXML 部件与关系保留，独立 openpyxl 验证普通数据修改后仍存在；不是 Canvas 内的对象编辑器。图表可随绘图部件保留，不提供图表编辑/重算能力。含这些保留对象的工作表暂时拒绝复制和行列插删，避免对象锚点或表范围失配；不承诺表头改名后同步结构化列名，也不承诺未知结构化公式的计算。
- 保留对象也进入 JSON 快照（编码后的二进制部件），会增加快照体积和内存。其他未识别扩展仍可能有损，不能把对象保留机制视为完整 OOXML 保真。

内部复制使用 HTML 来源标记关联快照，外部相同文本不会回放旧公式或样式；工具栏与键盘剪贴板均携带文本和 HTML。仅有纯文本剪贴板能力的环境按外部文本处理。剪切要求同工作簿、源工作簿版本未变化，以及连续可见的源和目标；跨隐藏行列的目标会明确拒绝，避免覆盖不可见数据。

普通复制/粘贴携带数据验证与条件格式；仅格式粘贴携带条件格式。规则按实际可见目标映射，跳过隐藏间隔，撤销同时恢复规则、合并和内容。外部普通粘贴保留自动识别的日期/百分比格式及受支持的 HTML 内联字体和对齐，仍不保证完整网页或 Excel 剪贴板样式。条件格式文件结构参考 [Microsoft DXF 文档](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.differentialformat)。

## 宿主 SDK 扩展

支持五语言运行时切换、工具栏白名单/图标文字自定义操作、文件保存回调、Worker 工厂、资产复制、版本握手/超时、错误码、变更来源和保存点、对象记录与分块读写，以及可选 React/Vue 组件。契约见 [SDK 指南](sdk.md)。

自定义函数由可信 Worker ES 模块提供，支持同步标量和矩形动态数组；异步函数、网络数据自动刷新、在线注册/卸载函数不在当前契约内。Excel 不执行 JS 自定义函数；导出保留原公式并返回兼容诊断。业务校验在事务提交和导入替换之前运行，拒绝则整体回滚；undo/redo 恢复历史，不重新校验。

## 保存与使用体验

可选持久化控制器支持自动保存、保存状态、有限重试、原生离页提示和显式草稿恢复。宿主选择存储，内置 IndexedDB；后台只保存已提交修改。每个文档键仅支持一个写入控制器，不提供跨标签页冲突合并、跨设备同步或未提交输入的崩溃恢复。大工作簿保存仍生成完整快照，不是增量存储。

问题面板按严重程度与工作表筛选，提供影响说明和定位；公式运行错误及溢出遮挡也进入诊断。50%～200% 为真实网格和输入框缩放，只属于视图状态；文件视图缩放仍不保留。格式刷复制基础格式与条件格式，不改值、公式和数据验证，不复制合并或行列尺寸；单次应用可撤销。
